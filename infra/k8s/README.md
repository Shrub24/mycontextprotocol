# Helmfile Deployment

This directory deploys the full stack into a single app namespace (`mycontextprotocol`) with operators in system namespaces.

## Prerequisites

- Helm + Helmfile
- SOPS + age
- A running Kubernetes cluster (k3s/k3d or equivalent)

## Secrets Setup

External API keys are stored in `infra/k8s/secrets/common.yaml` and rendered into a shared Secret named `mycontextprotocol-external`.

Required keys:
- `LLAMAINDEX_OPENAI_API_KEY`
- `LLM_BINDING_API_KEY`
- `EMBEDDING_BINDING_API_KEY`

Edit secrets:

```bash
task deploy:secrets:edit
```

## Deploy

```bash
task deploy
```

## Notes

- CNPG creates the internal app secret `mycontextprotocol-db-app` automatically.
- Dragonfly uses `dragonfly-password`, generated by the `dragonfly-secrets` release.
- All workloads read external keys from `mycontextprotocol-external`.
